Pipecat AI Web Client

Kế hoạch triển khai giao diện kết nối RTVI Web

v1.0 — 2026-05-12

1. Tổng quan

Mục tiêu: Xây dựng giao diện người dùng (GUI) để kết nối tới Pipecat AI Server thông qua giao thức RTVI (Real-Time Voice & Video Interface) qua WebSocket.

  • Pipecat Server: https://rtstt-demo.securityzone.vn/
  • WebSocket Endpoint: wss://aeon-pipecat.securityzone.vn/ws
  • GUI Deployment: https://web.securityzone.vn/ac/pipecat-client-web/
  • Yêu cầu: Chạy khác domain gốc (cross-domain CORS)

2.2 Binary WebSocket Protocol

Message format (Protobuf-like framing):

0x22 outer_len (varint) 0x0A json_len (varint) JSON payload

Giải thích:

ByteGiá trịÝ nghĩa
0x22Tag outerField number 4, wire type 2 (length-delimited)
outer_lenVarintĐộ dài phần bên trong (inner_len + 3)
0x0ATag innerField number 1, wire type 2 (JSON string)
json_lenVarintĐộ dài JSON payload
JSONUTF-8RTVI message JSON

Ví dụ message client-ready:

{
  "label": "rtvi-ai",
  "type": "client-ready",
  "data": {
    "version": "1.0.0",
    "about": {
      "library": "@pipecat-ai/client-js",
      "library_version": "1.4.0",
      "platform_details": { "browser": "Chrome", ... }
    }
  },
  "id": "25477a42"
}

2.3 RTVI Message Types

MessageDirectionMô tả
client-readyClient → ServerGửi ngay sau khi WebSocket connected
bot-readyServer → ClientBot sẵn sàng, kèm version
disconnect-botClient → ServerYêu cầu ngắt kết nối
user-transcriptionServer → ClientUser speech-to-text
bot-outputServer → ClientBot text response
errorServer → ClientLỗi kết nối

2.4 Audio Flow

  • Microphone: Capture via getUserMedia() → AudioWorklet → gửi binary audio qua WebSocket
  • Speaker (Bot audio): Nhận binary audio từ WebSocket → decode → play qua Web Audio API (AudioContext)

3. Ba phương án triển khai

A - HTML thuần

HTML thuần + JavaScript

Một file HTML duy nhất, mọi thứ đều inline. Không cần build tool, không cần npm. Deploy bằng copy file.

Ưu điểm: Tối giản, dễ deploy, không dependencies, chạy ở bất kỳ web server nào.

Nhược điểm: Không TypeScript, khó maintain khi phức tạp.

B - React

React + Vite + TypeScript

Ứng dụng React đầy đủ, dùng @pipecat-ai/client-react và @pipecat-ai/client-js.

Ưu điểm: Tận dụng React ecosystem, component-based, dễ mở rộng.

Nhược điểm: Cần build step, dung lượng lớn, cần cài dependencies.

C - Vite Vanilla

Vanilla JS + Vite + TypeScript

Vite project với vanilla TypeScript. Gọn nhẹ nhưng có build tool hỗ trợ.

Ưu điểm: TypeScript, bundle nhỏ, fast refresh, Dễ maintain hơn HTML thuần.

Nhược điểm: Cần build step, cần Node.js.

5.2 Encode/Decode Message (JavaScript)

// === ENCODE (gửi message) ===
function encodeMessage(jsonStr) {
  const encoder = new TextEncoder();
  const jsonBytes = encoder.encode(jsonStr);
  const jsonLen = jsonBytes.length;

  // innerLenVarint = varint(jsonLen)
  const innerLenVarint = encodeVarint(jsonLen);
  // outerLen = 1 (0x0A) + innerLenVarint.length + jsonLen
  const outerLen = 1 + innerLenVarint.length + jsonLen;
  const outerLenVarint = encodeVarint(outerLen);

  const msg = new Uint8Array(1 + outerLenVarint.length +
                             1 + innerLenVarint.length + jsonLen);
  let offset = 0;
  msg[offset++] = 0x22;
  outerLenVarint.forEach(b => msg[offset++] = b);
  msg[offset++] = 0x0A;
  innerLenVarint.forEach(b => msg[offset++] = b);
  msg.set(jsonBytes, offset);
  return msg;
}

// === DECODE (nhận message) ===
function decodeMessage(data) {
  let offset = 1; // skip 0x22
  while (data[offset] & 128) offset++; // skip outer_len varint
  offset++; // skip last byte of outer_len
  offset++; // skip 0x0A
  // read inner_len varint
  let jsonLen = 0, shift = 0;
  while (data[offset] & 128) {
    jsonLen |= (data[offset] & 127) << shift;
    shift += 7; offset++;
  }
  jsonLen |= (data[offset] & 127) << shift;
  offset++;
  return new TextDecoder().decode(
    data.subarray(offset, offset + jsonLen)
  );
}

// === VARINT ENCODING ===
function encodeVarint(value) {
  const bytes = [];
  while (value > 127) {
    bytes.push((value & 127) | 128);
    value >>>= 7;
  }
  bytes.push(value & 127);
  return bytes;
}

WebSocket Connected │ ├──▶ Gửi: client-ready │ {"label":"rtvi-ai","type":"client-ready", │ "data":{"version":"1.0.0","about":{...}}, │ "id":"<uuid>"} │ │◀── Nhận: bot-ready │ {"label":"rtvi-ai","type":"bot-ready", │ "data":{"version":"1.1.0", │ "about":{"library":"pipecat-ai","library_version":"0.0.99"}}, │ "id":"<uuid>"} │ │──▶ Trao đổi audio hai chiều │ (User mic → binary audio → Server) │ (Server → binary audio → Bot speaker) │ │◀── Nhận: user-transcription / bot-output (khi có hội thoại) │ │──▶ Gửi: disconnect-bot (khi nhấn Disconnect) │ WebSocket Closed

6. Hướng dẫn triển khai

Yêu cầu hệ thống

  • Web server (Nginx / Apache / IIS) để serve static files
  • Node.js 18+ (cho phương án B và C khi build)
  • Pipecat AI Server đang hoạt động tại wss://aeon-pipecat.securityzone.vn

CORS Configuration (Nginx)

# /etc/nginx/sites-available/web.securityzone.vn
location /ac/pipecat-client-web/ {
    alias /var/www/pipecat-client-web/;
    add_header Access-Control-Allow-Origin *;
    add_header Access-Control-Allow-Methods "GET, POST, OPTIONS";
    add_header Access-Control-Allow-Headers "*";
    try_files $uri $uri/ =404;
}

Base Path Configuration

Với GUI deploy tại subdirectory /ac/pipecat-client-web/:

  • Approach A (HTML thuần): Chỉ cần copy file index.html vào thư mục
  • Approach B (React): Set base: '/ac/pipecat-client-web/' trong vite.config.ts
  • Approach C (Vite): Set base: '/ac/pipecat-client-web/' trong vite.config.ts
